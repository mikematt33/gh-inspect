# Security Policy

## Supported Versions

`gh-inspect` is distributed as a single binary. Security fixes are applied to the
latest released version. Please ensure you are running the most recent release
before reporting an issue.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, use GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** to open a private advisory.

Alternatively, you can email the maintainer at **<security@example.com>** (replace
with your preferred contact address).

When reporting, please include:

- A description of the vulnerability and its impact.
- Steps to reproduce or a proof of concept.
- The version of `gh-inspect` affected (`gh-inspect --version`).
- Any relevant configuration or environment details.

## Response Process

- We aim to acknowledge new reports within **5 business days**.
- Once triaged, we will work on a fix and keep you updated on progress.
- After a fix is released, we will publicly disclose the issue and credit the
  reporter (unless you prefer to remain anonymous).

Thank you for helping keep `gh-inspect` and its users safe.
